# FTP 高效提升專項指南與課表 (Based on FTP 205W)

本指南專為 **現行 FTP = 205 W** 的鐵人三項選手設計。深入剖析提升 FTP 的生理機制（VO2max 天花板與乳酸清除能力），並提供量化功率課表、4 週輪替循環與突破關鍵輔助策略。

---

## 一、 FTP 提升的核心生理機制
FTP (Functional Threshold Power) 代表在 1 小時內能維持的最大平均功率，由兩個核心要素決定：
1. **最大攝氧量 (VO2max — 引擎天花板)**：代表最大吸氧能力。天花板越高，潛力越大。
2. **乳酸閾值百分比 (% of VO2max — 天花板利用率)**：代表肌肉能在多高強度下「邊高速踩踏、邊清除乳酸」。

---

## 二、 四大高效率 FTP 提升專項課表 (FTP 205W 量化)

### 1. Sweet Spot (甜心區間：88% - 94% FTP) — 最經濟高效瓦數累積
- **目標瓦數 (FTP 205W)**：**180 W - 193 W** (目標定在 **185 W**)
- **特點**：強度剛好低於乳酸閾值，疲勞累積慢、恢復快，能最大化刺激線粒體增生與毛細血管密化。
- **菜單**：15m 熱身 ➔ **3 x 15 分鐘 @ 185W** (組間休息 4 分鐘 110W 輕鬆踩) ➔ 15m 緩冷。

### 2. Threshold (乳酸閾值間歇：95% - 105% FTP) — 直接攻克 FTP 本體
- **目標瓦數 (FTP 205W)**：**195 W - 215 W** (目標定在 **205 W**)
- **特點**：直接在 FTP 本體強度踩踏，強化心理耐受力與乳酸清除效率。
- **菜單**：15m 熱身 ➔ **4 x 8 分鐘 @ 205W** (組間休息 4 分鐘 110W 輕鬆踩) ➔ 15m 緩冷。

### 3. Over-Under (過衝/拉回間歇) — 訓練高速清除乳酸能力
- **目標瓦數 (FTP 205W)**：Over **215 W (105% FTP)** / Under **185 W (90% FTP)**
- **特點**：在 215W 產生乳酸，接著降至 185W 強迫肌肉在高速運轉中將乳酸轉化為能量。
- **菜單**：15m 熱身 ➔ **3 組 x 12 分鐘 Over-Under** (每組包含 4 次：[2m @ 215W + 1m @ 185W]，組間休息 5m 110W) ➔ 15m 緩冷。

### 4. VO2max (最大攝氧量間歇：108% - 120% FTP) — 打開瓦數天花板
- **目標瓦數 (FTP 205W)**：**220 W - 245 W** (目標定在 **230 W**)
- **特點**：極短時間高瓦數刺激，把最大吸氧能力衝高，打破 FTP 停滯瓶頸。
- **菜單**：15m 熱身 ➔ **5 x 3 分鐘 @ 230W** (迴轉數 95-100 rpm，組間休息 3m 110W) ➔ 20m 緩冷。

## 四、 FTP 突破的四大關鍵輔助策略
1. **高踏頻踩踏 (High Cadence Strategy)**：間歇維持 **90 - 98 rpm**，減輕肌肉疲勞並將負荷轉移給心血管。
2. **訓練後 30 分鐘黃金補給**：補充 3:1 或 4:1 的碳水與蛋白質（如 60g 碳水 + 20g 蛋白質），加速糖原合成與肌肉修復。
3. **騎行台 ERG 模式訓練**：強迫雙腿輸出精確瓦數，不給降瓦偷懶空間。
4. **4-6 週重新測試 FTP (Ramp Test)**：定期重新測驗並更新功率區間，持續推升訓練刺激。
